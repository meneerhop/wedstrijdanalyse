# Wedstrijdanalyse ASC Nieuwland 3

Scoutingsrapport van Wasmeer 2 voor de uitwedstrijd van zaterdag 28 november 2026.

## Online zetten met GitHub Pages

1. Maak op github.com een nieuwe repository aan, bijvoorbeeld `wedstrijdanalyse`.
2. Klik op **Add file → Upload files** en sleep de inhoud van deze map erin
   (`index.html`, `README.md` en de map `assets`). Klik op **Commit changes**.
3. Ga naar **Settings → Pages**. Kies bij *Source* **Deploy from a branch**,
   branch **main** en map **/(root)**, en klik op **Save**.
4. Na een minuut staat de pagina op
   `https://<jouw-gebruikersnaam>.github.io/wedstrijdanalyse/`.

Let op: een GitHub Pages-site is openbaar. Iedereen met de link kan hem bekijken.

## Inhoud

- `index.html`: de complete pagina, alle cijfers zitten erin.
- `assets/`: clublogo's en d3.js voor de grafieken. Er is geen internetverbinding naar andere sites nodig.
